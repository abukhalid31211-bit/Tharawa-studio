# ثروة كابيتال — Tharwah Capital

منصة استشارات استثمارية عربية/إنجليزية يدير موظفوها العملاء والمحافظ والطلبات والمحتوى يدوياً من لوحة إدارة موحدة.

## البنية

- الواجهة: React 19 + Vite + TanStack Router + TanStack Query + Tailwind CSS v4.
- الاستضافة الأمامية: Vercel على `www.yourdomain.com`.
- الخادم: Node.js + Express على VPS خاص عبر `api.yourdomain.com`.
- قاعدة البيانات: PostgreSQL على الشبكة الخاصة للخادم.
- ORM: Prisma.
- التحديث اللحظي: Socket.io موثق برمز الوصول.
- Reverse proxy وTLS: Nginx.
- إدارة العملية: PM2.

## طبيعة التشغيل

كل العمليات استشارية ويديرها الموظف من لوحة الإدارة. طلبات الإيداع والسحب وحالات التحقق والأسواق والإشعارات والمواعيد هي تدفقات داخلية يراجعها الموظف يدوياً. لا تنفذ المنصة تداولاً أو دفعاً خارجياً.

## أوامر المشروع

### الواجهة

- `npm install`: تثبيت الاعتماديات.
- `npm run dev`: تشغيل بيئة التطوير.
- `npm run build`: فحص TypeScript وبناء الإنتاج.
- `npm test`: تشغيل الاختبارات.
- `npm run lint`: فحص جودة الكود.

### الخادم

توجد أوامر التثبيت والبناء والترحيل والتشغيل داخل `backend/package.json`. يجب تطبيق migrations قبل بدء إصدار الخادم الجديد.

## متغيرات البيئة

- استخدم `.env.example` للواجهة.
- استخدم `backend/.env.example` للخادم.
- لا تحفظ ملف البيئة الحقيقي في Git.
- جميع القيم التي تبدأ بـ `VITE_` تكون متاحة للمتصفح، ولذلك لا توضع فيها أسرار خادمية.

## البيانات والتحديث اللحظي

- PostgreSQL هو مصدر الحقيقة لبيانات العمل.
- التخزين المحلي مخصص لتفضيلات العرض غير الحساسة وفallback التطوير فقط.
- التعديلات العامة على المحتوى تصل إلى الزوار مباشرة.
- تعديلات العميل والمحفظة والطلبات تصل إلى العميل المعني وإلى لوحة الإدارة.
- هوية غرف Socket.io مشتقة من JWT الموثق ولا يحددها المتصفح.
